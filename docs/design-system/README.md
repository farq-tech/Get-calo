# Calora Design System v1.0

Source specimen from Claude Design (`Get-calo design system.zip`).

## Tokens

Implemented in `mobile/src/theme/`:

- `colors.ts` — dark camera + light analysis surfaces, teal accent
- `typography.ts` — Syne (brand/numbers) + IBM Plex Sans Arabic (UI)
- `tokens.ts` — spacing (8pt), radius, elevation, motion

## Specimens

Open `Calora Design System.dc.html` with `support.js` in the same folder (or unzip the archive).

## Product rules

- Dark mode is the product default for camera chrome
- Bright analysis overlay for scan progress
- Teal/emerald only for success, health, and primary actions
- No purple, cream, or terracotta
